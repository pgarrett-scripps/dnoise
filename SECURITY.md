# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues **privately**. Do not open a public GitHub issue
for a vulnerability.

You can report a vulnerability in either of these ways:

- Email **Patrick Garrett <pgarrett@scripps.edu>**.
- Open a private report through
  [GitHub Security Advisories](https://github.com/pgarrett-scripps/dnoise/security/advisories/new).

Please include a description of the issue, the affected version, and steps to
reproduce if possible.

## Response Time

`dnoise` is academic research software maintained on a best-effort basis. We
will do our best to acknowledge reports and respond as promptly as we can, but
we cannot guarantee a fixed response window. Thank you for helping keep the
project and its users safe.
